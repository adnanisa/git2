# بوابة معهد الدراسات القضائية والقانونية
نموذج تفاعلي ثنائي اللغة لإدارة التدريب — مملكة البحرين.

**الصفحة الرئيسية: index.html. جميع الملفات في مجلد واحد. لا توجد خطوة بناء ولا مكتبات تشغيل خارجية.**

## الرفع على GitHub Pages
1. فك ضغط jlsi-portal.zip.
2. أنشئ مستودع GitHub أو افتح مستودعك.
3. ارفع **محتويات المجلد** إلى جذر المستودع، بحيث يظهر index.html مباشرة بجوار README.md، وليس داخل مجلد فرعي.
4. من Settings → Pages اختر Deploy from a branch، ثم main و / (root)، واحفظ.
5. انتظر النشر وافتح رابط الموقع الذي يعرضه GitHub Pages.

ارفع جميع ملفات HTML وJavaScript وCSS والخطوط وfavicon.svg. ملف .nojekyll مرفق لتعطيل معالجة Jekyll، لكنه قد لا يظهر في مدير الملفات. الروابط نسبية، وتعمل أيضًا في موقع مشروع تحت /repository-name/.

مرجع GitHub الرسمي: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## التشغيل محليًا
يمكن فتح index.html للمعاينة البصرية. لضمان استمرار البيانات بين الصفحات، استخدم خادمًا محليًا؛ سلوك localStorage عند فتح file:// يختلف بين المتصفحات.

إذا كان Node.js مثبتًا، افتح الطرفية داخل المجلد:
~~~
node serve.cjs
~~~
ثم افتح http://127.0.0.1:8080/ . لإيقاف المعاينة اضغط Ctrl+C.

بديل إذا كان Python مثبتًا:
~~~
python -m http.server 8080
~~~

لا يحتاج الموقع Node.js أو Python عند نشره على GitHub Pages. يلزم JavaScript ومتصفح حديث.

## تجربة سريعة للإدارة
- الصفحة الرئيسية: البحث والتصفية والوصول إلى 12 خدمة.
- تبديل اللغة والدور من الشريط العلوي؛ A+ لتكبير النص.
- البرامج: أنشئ برنامجًا، ثم افتح تفاصيله ← الاعتمادات، وأكمل المراحل الثلاث.
- الموافقة الخارجية اختيار مستقل إذا كان البرنامج يتطلبها؛ تسجيلها محاكاة فقط.
- سجّل طلبًا بمعرّف DEMO-900. اعتمده من الطلبات ثم راجع المقاعد والحضور.
- استخدم معرّفًا آخر لطلب جديد عندما يكون البرنامج ممتلئًا لتجربة قائمة الانتظار.
- الحضور: اختر البرنامج واليوم. تعديل حالة محفوظة يتطلب مبررًا.
- الدرجات: أدخل الاختبار والتكليف؛ النهائي هو متوسطهما.
- الشهادات: البرنامج «إدارة الجلسات القضائية» يحتوي على أمثلة مستحقة وغير مستحقة.
- من معاينة الشهادة اختر طباعة / حفظ PDF. اختر A4 أفقيًا وأوقف ترويسة وتذييل المتصفح إذا ظهرا.
- جرّب التقييم والمصروفات ثم راجع التقارير.
- من الإعدادات يمكن تعديل معايير الشهادة أو إعادة ضبط النموذج بعد التأكيد.

## المنفذ فعليًا داخل النموذج
- واجهة عربية RTL وإنجليزية LTR، وتفضيلات محفوظة، و6 أدوار عرض.
- إنشاء البرامج والتحقق من الحقول والأرقام والتواريخ، ومسار اعتماد داخلي من 3 مراحل.
- تسجيل فردي وترشيح جهة مع منع الطلب النشط المكرر بالمعرّف والبرنامج.
- اعتماد ورفض بسبب إلزامي وقائمة انتظار عند امتلاء المقاعد؛ الاعتماد يحدّث المقاعد.
- المشاركون في الحضور والدرجات والشهادات مشتقون من الطلبات المعتمدة لكل برنامج.
- الحضور بحسب البرنامج والتاريخ مع سبب للتصحيح، وتصدير CSV بترميز UTF-8 مع BOM.
- الدرجات من 0–100، وحساب المتوسط، وإعادة حساب أهلية الشهادات.
- شهادة قابلة للطباعة تحمل وسمًا تجريبيًا، وأسباب عدم الاستحقاق ظاهرة.
- التقييمات بأنواعها الثلاثة مرتبطة بالبرامج وتؤثر في التقارير.
- المصروفات بالدينار البحريني بدقة 3 خانات عشرية مع دورة اعتماد وصرف.
- مرفقات PDF وPNG وJPEG وWebP وTXT حتى 500 × 1024 بايت لكل ملف، مع تنزيلها.
- معاينة الصور في الأرشيف، وإضافة المدربين وعرض برامجهم.
- مؤشرات مشتقة من البيانات، وقائمة أنشطة محلية، وتصدير البرامج.
- إعادة ضبط مقصورة على بيانات هذا النموذج؛ لا تمس بيانات المواقع أو التطبيقات الأخرى.

## المحاكاة والحدود
هذا نموذج لمراجعة تجربة العمل، وليس نظامًا تشغيليًا أو موقعًا رسميًا:
- جميع الأسماء والبيانات عينات افتراضية. رمز الميزان توضيحي وليس شعار المعهد الرسمي.
- تبديل الأدوار يغير الواجهة فقط. لا مصادقة أو صلاحيات أمنية أو عزل بيانات.
- لا خادم خلفي أو قاعدة بيانات مشتركة أو مزامنة بين الأجهزة والمستخدمين.
- localStorage خاص بالمتصفح والموقع. حذف بيانات الموقع يمسح العمل. الملفات تحفظ كـ Data URL ضمن نفس الحصة المحدودة.
- عند تعذر الحفظ تظهر رسالة ولا تعتمد العملية في الذاكرة. لا يوجد حفظ سحابي.
- الجلسات مبسطة: جلسة واحدة لكل يوم ضمن فترة البرنامج؛ لا توجد عطلات أو أوقات جلسات تشغيلية.
- استحقاق الشهادة يشترط اكتمال سجل الجلسات وتجاوز حدي الحضور والنتيجة. 80% و60% قيم عرض وليستا سياسة رسمية.
- البرنامج المكتمل لا يقبل تسجيلًا جديدًا. قائمة الانتظار تحتاج إعادة اعتماد يدويًا عند توفر مقعد؛ لا توجد رسائل تلقائية.
- الموافقات الداخلية والخارجية وحالة الدفع حالات تجريبية فقط. لا تحويلات مالية أو تكاملات حكومية.
- تقييم أثر التدريب بعد ثلاثة أشهر تصنيف يدوي، دون جدولة أو إرسال.
- لا تخزن بيانات شخصية حقيقية أو معلومات سرية.

## English quick start
Upload the **contents** of this folder to your GitHub repository root. Keep index.html at the root. Enable GitHub Pages from main / root. No build step, npm installation or runtime dependencies are needed.

For local preview with Node.js, run node serve.cjs and open http://127.0.0.1:8080/. Use HTTP rather than file:// for consistent cross-page localStorage.

This bilingual prototype implements the training lifecycle with browser-local persistence. All data is fictional. Role switching, approvals and payments are demonstrations, not authentication, authorization, official approvals or money transfers. No shared backend or external integrations are included. See the in-app English User guide for workflows and limitations.

Run domain tests with:
~~~
node --test core.test.cjs
~~~
